# 儿童故事插画分镜生成规则

默认使用“四宫格漫画节奏模式”：每张母图生成四个连续、可切分的 3:2 小分镜。

## 前置流程

生成任何插画之前，必须先通读故事，同时输出文字版分镜故事简介和一份结构化 JSON。简介必须列出分镜数量、每个分镜的单一主要动作或情绪、角色、场景、光线、情绪及与前后分镜的衔接。JSON 除了这些分镜规划信息，还必须包含每个分镜对应的原文段落或原文摘录，用于追溯画面来源。完成文字简介和 JSON 后，才开始生成分镜插画。

JSON 至少使用以下结构：

```json
{
  "storyTitle": "故事名称",
  "sheetCount": 20,
  "visualStyle": "统一的画风和材质说明",
  "characterBible": [
    {
      "id": "donkey",
      "name": "驴子",
      "fixedAppearance": "固定外形、年龄/性别、颜色、服饰和道具",
      "visualSignature": "可一眼辨认的剪影、配色、头饰或标志道具",
      "personality": "稳定的性格与姿态倾向"
    }
  ],
  "sheets": [
    {
      "id": "01",
      "summary": "本母图的简短画面简介",
      "originalText": "与本分镜对应的故事原文段落或连续原文摘录",
      "scene": "地点、时间和必要背景",
      "continuity": "与前后分镜的动作、位置或情绪衔接",
      "subPanels": ["01-01 的单一动作", "01-02 的单一动作", "01-03 的单一动作", "01-04 的单一动作"],
      "imagePrompt": "最终用于生成该四宫格母图的提示词"
    }
  ]
}
```

`originalText` 必须来自故事原文，不得凭空编造；可引用一个或多个连续段落，但应覆盖本分镜画面依据。不得为了凑字段而改写原文。若一个原文段落被拆为多个分镜，应在每个分镜中标明对应的原文摘录，并通过 `continuity` 说明拆分关系。

## 1. 分镜规划

- 按故事情节和时间顺序拆分母图；中长故事通常为 18–40 张，母图数量必须根据完整音频时长计算，而不是固定套用某个故事的数量。
- 每个母图包含 4 个连续子镜头，每个子镜头只表现一个主要动作或情绪变化。
- 分镜必须覆盖角色介绍、冲突出现、事件发展、转折、结果和情感收束。
- 相邻分镜之间必须有明确的动作、位置或情绪衔接。

## 2. 画面规格

一次生成一张 2×2 母图，再切成四张独立插画。该模式不等同于把已有图片随意裁成四块；四个小格必须是按阅读顺序连续创作的四个完整小分镜。

- 母图为 2 列 × 2 行，阅读顺序固定为左上、右上、左下、右下。
- 每个小格必须是完整的 3:2 横版，且不小于 320×240；推荐小格 360×240，对应母图 720×480。若生成工具输出更高分辨率，只要总比例正确即可，随后在本地精确切分、缩放。
- 2×2 母图的整体比例同样为 3:2。为便于等分切图，不要让人物、飞箱、道具、对白或背景跨越中线；如使用分隔线，切分时必须去除，不能留在成品边缘。
- 每个小格只表现一个动作、反应或镜头变化，必须形成完整的微型连续过程，而不是同一画面的随机放大或空景。
- 母图不添加序号、标题、对白或其他文字。切分后的文件名承担顺序，例如 `01-01.png`、`01-02.png`、`01-03.png`、`01-04.png`。
- 先取得完整音频实际时长 `D`（秒），以每个子镜头目标停留约 8 秒计算：`基础母图数 = round(D / (4 × 8))`。当音频时长大于 3 分钟时，使用 `母图数 = clamp(18, 40, 基础母图数)`；当音频时长不超过 3 分钟时，允许母图数低于 18，直接采用基础母图数并按语义微调，避免为达到下限而造成无意义的过快切换。任何情况都不能为了凑数加入空景或重复画面。示例：约 12 分钟音频会得到约 23 张母图、92 个子镜头，平均约 8 秒/格。
- 后续时间轴以切分后的子图为单位。每张子图必须对应连续的音频片段，或对应同一长音频片段中的明确时间范围；首尾覆盖完整音频，不得有空档或重叠。

## 3. 角色连续性

- 主角的外形、颜色、服饰、道具和比例在所有分镜中保持一致。
- 先为主角设定固定视觉特征，例如颜色、脸型、配饰或身体结构。
- 当故事含有月份、兄弟姐妹、旅客等同类群像角色时，`characterBible` 必须为每人明确至少三项可一眼辨认的差异：年龄或体型/剪影、主色与辅色、发型或头饰、标志道具。不得只把多个相似角色换成不同颜色的外套；同一画面出现多人时，提示词必须重复这些视觉签名。
- 若角色对应连续季节、月份或时间段，角色设计还必须服从整体色彩与情绪弧线，并在 JSON 写明分段规则；相邻阶段缓慢过渡，不能把每位角色做成孤立、同强度的“主题服装”。
- 对月份等具名角色组，先建立并锁定“角色设定表”：每人必须有明确的年龄、性别、服装、标志道具、主色与辅色、性格倾向；将其写入 `fixedAppearance`、`visualSignature` 和 `personality`。后续分镜不得任意改变这些基础项。
- 故事动作所需的日历、花束、雨伞、工具、礼物等属于“剧情附加道具”：可以在不遮蔽角色视觉签名的前提下增加，不能用它替代、反转或改写角色设定（包括年龄与性别）。原文使用泛称或与角色设定不同的代词时，画面以已确认的角色设定表为准，原文只作为动作依据保留。
- 季节角色组默认按四段节奏组织：1–3 月为冷色、克制到新生（允许二月以低饱和暖色作期待点缀）；4–6 月为花叶、湿润与清新；7–8 月为全年唯一的高饱和、热烈外放峰值；9–12 月由收获土色逐步收束至深冷色，情绪转向成熟、守护与团聚。具体故事可调整，但必须在 JSON 的 `seasonalCharacterArc` 中声明。
- 表情和姿态必须随故事发展自然变化。
- 不随意增加无关角色、物品或场景。

## 3.1 分镜衔接与场景连续性

- 相邻分镜必须像同一部连续动画的前后镜头：前一幅的结尾动作、视线方向、人物站位和关键道具位置，要自然承接到后一幅的开头。
- 每个分镜的 `continuity` 必须明确写出与前后分镜的连接锚点，至少包含人物位置、动作延续、关键道具或场景方位中的一项；不能只写“承接上一幅”。
- 同一地点必须保持稳定的空间关系，例如城门、邮车、广场、窗户、道路和树木的左右相对位置不得无理由改变；需要切换视角时，必须在 `continuity` 和 `imagePrompt` 中说明镜头切换。
- 同一角色在相邻画面中的身高比例、脸型、服饰颜色、配饰、携带物和受光方向必须保持一致；角色离场或换装必须有故事依据。
- 同一件道具必须保持外形和状态连续；道具被交接、打开、收起或改变状态时，后一幅必须继承该状态。
- 时间、季节、天气和光线变化必须渐进。除非原文明确跳转，否则不得在相邻分镜中突然改变季节、时间段、天气或整体色调。
- 每个分镜只允许一个主要动作，但动作要处在完整过程中的明确阶段：前一幅留下后一幅的动作起点，后一幅呈现前一幅动作的结果或下一步。
- 生成前应为每个分镜写出“上一幅结束状态”和“本幅开始状态”；生成后必须逐对检查相邻画面，发现人物、道具、空间或光线断裂时，重写提示词并重新生成。
- 不得因为追求单幅画面完整而重复加入已经离场的角色，也不得让尚未登场的角色提前出现；群像画面必须与前后出场顺序一致。

## 4. 统一画风

同一个故事必须统一画风，根据故事风格选择具体媒介。默认使用温暖、柔和、友善的儿童绘本风格；推荐水彩、彩铅、蜡笔或轻柔绘本质感；使用明亮但不刺眼的高明度配色；轮廓圆润、表情清楚，避免写实、尖锐、阴暗或惊吓感。所有分镜必须保持统一的光线、材质和绘画风格。

## 5. 对话和文字

- 默认不生成对白气泡，避免文字乱码。
- 如确实需要对白，只保留极短、简单的指定内容。
- 对话文字必须严格按照指定内容生成。
- 不加入故事原文、解释文字或额外标题。

## 6. 安全与适龄要求

- 适合 2–6 岁儿童观看。
- 冲突和意外必须安全、温和，不出现伤口、恐怖、破碎飞溅或强烈负面画面。
- 角色即使失败、受损或难过，也要保持温暖和可接受的视觉表达。
- 避免复杂背景、危险行为、尖锐物品特写和过度戏剧化的阴影。

## 7. 四宫格母图提示词模板

```text
Use case: illustration-story
Asset type: one children’s storybook FOUR-PANEL GRID, exactly 2 columns by 2 rows, overall horizontal 3:2
Primary request: Mother sheet [母图 ID]. Four sequential micro-storyboard actions: top-left [动作 1]; top-right [动作 2]; bottom-left [动作 3]; bottom-right [动作 4]
Grid constraints: every cell is an independently usable 3:2 landscape illustration; no character, prop or scene element crosses a grid boundary; reading order is top-left, top-right, bottom-left, bottom-right
Visual continuity: [主角固定外观、关键道具、人物站位、光线和空间锚点]，四格中保持一致并按动作渐进
Scene: [共同地点与必须保持不变的背景方位]
Style/medium: warm hand-painted children’s picture book, soft watercolor and colored-pencil texture, rounded friendly character design
Composition/framing: clear 2x2 grid, each cell readable on a small screen
Text: no numerals, no captions, no speech bubbles, no words
Constraints: safe for young children, no watermark, no logo
Avoid: photorealism, scary imagery, harsh shadows, random letters, clutter, duplicated characters, objects crossing gutters
```

## 8. 输出前检查

- 是否先输出了文字版分镜故事简介？
- 是否按故事发生顺序排列？
- 分镜数量是否为 8–30 个？
- 每张是否只有一个主要动作或情绪变化？
- 是否覆盖角色介绍、冲突、发展、转折、结果和情感收束？
- 相邻分镜是否有明确衔接？
- 是否逐对检查了角色外观、站位、视线、动作、道具状态、背景方位、季节天气和光线？
- 是否至少保留一个跨分镜视觉锚点，并在相邻提示词中重复说明其位置和状态？
- 主角是否前后一致？
- 是否每个小格均为完整 3:2、至少 320×240，且已按左上→右上→左下→右下检查动作连续性？
- 是否每格都是独立叙事画面，而非随意裁切、空景或人物被中线截断？
- 是否确认四宫格没有任何序号或文字？
- 是否没有多余文字、水印、Logo 和随机角色？
- 是否适合 2–6 岁儿童观看？
- PNG 是否非空且可正常打开？

## 仓库文件约定

母图保存到 `四宫格插画/01.png`，切分后保存到 `四宫格插画/切分/01-01.png` 至 `01-04.png`。生成新图前必须检查已有图片并保留用户素材；不得随意覆盖已有文件，除非用户明确要求替换。

## 交付物提交约束

完成插画任务后，必须确认并提交原始 `故事.txt`、对应的四宫格分镜 JSON、母图和全部切分子图。插画不能只停留在对话附件中，必须先保存到仓库目录，检查文件非空且格式正确，再纳入 Git 提交。除非用户明确要求，否则不得把这些交付物加入 `.gitignore`。

## 云环境生成、归档与推送流程

平台的 `image_gen.imagegen` 会将每次生成的普通 PNG 临时保存到云环境的 `/workspace/generated_images/`。不要尝试从对话图片、内部 URL 或 Base64 内容恢复文件；应从该临时目录取得实际生成的 PNG。

## 9. 四宫格生成、切分与归档流程

1. 先在分镜 JSON 中记录母图、四个子镜头、原文依据、固定角色外观和四格衔接锚点。
2. 单独生成一张四宫格母图；生成器不能可靠锁定像素尺寸时，优先约束为 2×2、总比例 3:2、四格不跨线，而不是反复要求精确像素值。
3. 检查母图非空、可解析，确认四格均完整且动作顺序正确；发现角色服装、道具、光线或空间断裂时，重写提示词后仅重生成该母图。
4. 使用本地工具将母图精确切成四张，再统一缩放到不低于 320×240 的 3:2 尺寸。切分后逐张检查，不得保留网格线、裁掉脸部或留下跨格物体。
5. 为每张子图建立音频时间轴项。短对话可独占一格；长旁白可按语义在同一音频片段内部划分连续时间范围。所有子图共同覆盖完整音频。
6. 提交母图、切分子图、四宫格分镜 JSON，以及更新后的时间轴 JSON 和 LRC。
